# DevSecOps Portfolio

A hands-on DevSecOps portfolio integrating CI/CD, SAST, IaC, and AWS automation.

## Includes
- React + Vite frontend
- GitHub Actions for CI/CD
- Terraform for AWS S3 hosting
- Pre-commit hooks (Gitleaks, ESLint)
- Security scans (Snyk, Checkov)

## Secrets to set in GitHub
- AWS_ACCESS_KEY_ID
- AWS_SECRET_ACCESS_KEY
- SNYK_TOKEN
